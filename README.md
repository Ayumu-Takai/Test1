# Mini Platformer (マリオ風ミニゲーム)

左右移動とジャンプでゴールを目指すシンプルなブラウザゲームです。土管や障害物（トゲ）が配置されています。

## 操作方法

- 左移動: `←` または `A`
- 右移動: `→` または `D`
- ジャンプ: `↑` または `W` または `Space`
- 再スタート: 画面上の `再スタート` ボタン

## 目的

画面右側にある黄色いブロック（ゴール）に到達してください。トゲに触れるとリセットされます。

## ファイル構成

- `index.html` — ゲームのエントリ（Canvas）
- `assets/css/styles.css` — スタイル
- `assets/js/main.js` — ゲームロジック（物理、衝突、カメラ）

## ローカルでの実行

簡易HTTPサーバを使うと良いです（推奨）:

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。
